# UI (menus and screens)
## Rule
Same screens and look as the legacy game: title (warp stars, galaxy, planet, logo that shakes on directional input, sound-unlock veil), hub (8 skewed tiles, graph navigation, chips with the current rules, description bar, player card with level from XP = wins*3 + KOs + games), 0.55 s oblique-band transition between screens. Character select: every keyboard / pad joins with Attack, moves on the grid, Attack = ready, Parry = try the fighter in a live arena behind the menu (playground), Start / Enter when everyone is ready = fight; nobody joined = CPU BATTLE; FREE FOR ALL / TEAM BATTLE toggle with team flags per card. CPU fighters get character (seed + 3i) % roster. Keyboard, pointer (hover/click regions), pad and touch all reduce to nav events (up/down/left/right/ok/back/reset/tabL/tabR/start/sel).
## Legacy
`function drawTitle`, `function titleBG`, `function uiBG`, `function uiTrans`, `const HUB=`, `function drawMenu` (+ its wrappers: hubFX/hubProfile, HUBG graph `hubMove=`), `function ornFrame`, `function nav(` / `function onKey(` wrapper chains, `saveOpts`/`loadOpts`. Oddities: the FIGHT tile text is overridden by the character-select wrapper; `Digit1` = ok on the hub.
## Port
- Router: `packs/ui/app.ts` (`renderUi`, `nav`, `onKey`, `APP.mode`); shell `src/main.ts` (pointer hot regions, first gesture only unlocks audio).
- Screens: `packs/ui/screens/title/title.ts`, `packs/ui/screens/title/bg.ts`, `packs/ui/screens/hub/hub.ts`, `packs/ui/screens/hub/deco.ts`, `packs/ui/screens/hub/icons.ts`; shared `packs/ui/core.ts` (UiCtx, fonts, skewRect, ornFrame), `packs/ui/bg.ts`, `packs/ui/trans.ts`.
- Character select: `packs/ui/screens/css/state.ts` (`cssOpen`, `cssTick`, `cssGo`, `cssTapTile`), `packs/ui/screens/css/draw.ts`; character art through `packs/render/ld/portrait.ts` (`drawCharArt`); roster texts = `role` / `desc` of each character content file.
- Devices + bindings: `packs/ui/input/devices.ts` (`devIn` menu reading, `readDev` fight reading with pad chords), `packs/ui/input/binds.ts` (`sf_binds3`). The shell keeps a one-frame tap buffer (legacy tapQ) so a press shorter than a frame still counts.
- Fight overlays: `packs/ui/screens/fight/overlays.ts` (`drawIntro` READY?/FIGHT!, `drawGameEnd` GAME!, `drawPause` + menu with quit confirm, `PZ`), routed by `renderFightUi` / `fightKey` in `packs/ui/app.ts`; auto-pause on blur / hidden tab / pad unplugged (shell).
- Results: `packs/ui/screens/fight/results.ts` (`rankList`, `resAwards` titles, podium + art, stats panel, MATCH FLOW curve sampled every 30 frames by the shell, confetti); hub stats (`sf_stats`) counted at results start. LAST STOCK! banner + camera punch-in: `lsCheck` / `drawLastStock` / `lsZoom` in overlays.ts, zoom applied through `VIEWZ` (`packs/render/view.ts`, also carries the reduced-effects zoom factor).
- Sub-menus: `packs/ui/screens/sub/draw.ts` (`drawSub`, `splitRow`, `RDESC`, stack `SUB`), rows in `packs/ui/screens/sub/menus.ts` (RULES, OPTIONS, HOW TO PLAY, TEAMS, SOUND); settings saved after each change (legacy only saved at match start). Screens not ported yet open an honest 'Coming soon' sub-menu instead of a dead button. Rules reach the match: lives, items, cards at once, tempo, teams, COMPETITIVE (4 lives, no items); timer + map choice wait for lot 4.
- Item list: `packs/ui/screens/items/items.ts` (catalog = item content in legacy order, per-item ON/OFF -> match `itemSet`, `sf_opts.itemOn`). Item `name` / `color` / `desc` / `ch` now carry the legacy strings.
- Controls: `packs/ui/screens/binds/binds.ts` (keys incl. mouse buttons + wheel, pad buttons, Spell = 2-button chord, live test rows, pad test line, mouse-aim toggle `sf_mouse` — the in-fight mouse aim itself is not ported yet).
- Guide: `packs/ui/screens/info/info.ts` + the 40 legacy pages copied verbatim in `packs/ui/ld/info.ts` (`buildInfo(catalog)`: item pages follow the catalog). `tests/ld-names.test.ts` also checks `packs/ui/ld`.
- Touch: `packs/ui/input/touch.ts` (floating stick, thumb pad, AUTO fire, pause, results buttons, swipe-to-scroll lists, tap = click, landscape notice, fullscreen on first tap); the touch player is the first human. Pad menu navigation: `packs/ui/input/padnav.ts` (`pollNav`) -> `padEv` in app.ts.
- Effects tiers: `FXF` (`packs/render/ld/fx.ts`) feeds REDUCED / OFF to every verbatim draw file; OFF also applies `safeView` (`packs/render/juice/state.ts`) to each fight draw (no shake, zoom kick, blur, chroma, brightness, speed lines, inversion, particles, rings, beams, cracks; flashes capped at 0.06) and the overlays skip their full-screen white flashes and the last-stock heartbeat (deliberate: legacy still flashed there, DESIGN §25 R119).
- Match end: once a winner exists the sim only counts `winT` and ticks the effects (combat `gate`, legacy loop `stepFx();winT++`); the oracle runner does the same.
- Settings with the legacy storage keys: `packs/ui/settings.ts` (`SET`, `loadSettings`, `saveSettings`).
## Tests
`pnpm ui [scenario]` (`tools/ui/compare.ts`): legacy render() vs port per scenario (state + clock), op diff; run by `tests/parity/ui.test.ts`. Random decorations are copied legacy -> port, later Math.random pinned to 0.5.
## Bugs
- Legacy pad reading in the character select overwrote the vertical stick with the Y button (`I.y=bt(3)`): pads could not move up/down and Y moved down. Port keeps the team-flag button apart (`t`) — deliberate fix.
## Not ported yet
Replay (V), profiles, records, mouse aim in fight, training, online lobby, map maker, YouTube sidebar (`sb` = 0), CPU AI (CPUs stand still until lot 4), profiles' per-player bindings.
